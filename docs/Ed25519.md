# Ed25519 & Ed448 (Edwards-Curve Signatures)

Modern, high-security digital signatures based on Edwards curves. Ed25519 is the most popular choice for modern applications, offering 128-bit security, while Ed448 (Goldilocks) offers 224-bit security.

## Ed25519

Based on RFC 8032. It is fast, secure, and widely supported (e.g., SSH, TLS, Signal).

### Usage

```powershell
$ed = [Ed25519]::new()

# Generate a new keypair
$kp = $ed.GenerateKeyPair()
# $kp.PublicKey (32 bytes)
# $kp.PrivateKey (32 bytes seed)

# Sign a message
$message = [System.Text.Encoding]::UTF8.GetBytes("Sign me!")
$signature = $ed.Sign($message, $kp.PrivateKey) # 64 bytes

# Verify
$isValid = $ed.Verify($signature, $message, $kp.PublicKey)
```

---

## Ed448

A higher-security curve providing a 224-bit security level.

### Usage

```powershell
$ed448 = [Ed448]::new()

# Generate a new keypair
$kp = $ed448.GenerateKeyPair()
# $kp.PublicKey (57 bytes)
# $kp.PrivateKey (57 bytes)

# Sign
$signature = $ed448.Sign($message, $kp.PrivateKey) # 114 bytes

# Verify
$isValid = $ed448.Verify($signature, $message, $kp.PublicKey)
```

## Implementation Details

- **Ed25519**: Uses a pure PowerShell implementation based on TweetNaCl. It is platform-independent.
- **Ed448**: Uses the native .NET 8+ implementation when available.
