# Hc128

HC-128 is an eSTREAM portfolio stream cipher optimized for high software performance.

## Usage Example

```powershell
$key = [byte[]]::new(16); [System.Security.Cryptography.RandomNumberGenerator]::Fill($key)
$iv = [byte[]]::new(16); [System.Security.Cryptography.RandomNumberGenerator]::Fill($iv)
$plain = [System.Text.Encoding]::UTF8.GetBytes('Secret Stream')

$ciphertext = [Hc128Managed]::Encrypt($key, $iv, $plain)
$decrypted = [Hc128Managed]::Decrypt($key, $iv, $ciphertext)
```
