# Curve25519

Provides state-of-the-art highly secure Elliptic Curve Diffie-Hellman (ECDH) key agreement.

## Usage Example

```powershell
# Generate two keypairs
$alice = [Curve25519]::GenerateKeyPair()
$bob = [Curve25519]::GenerateKeyPair()

# Both derive the exact same shared secret:
$sharedSecretAlice = [Curve25519]::GetSharedSecret($alice.PrivateKey, $bob.PublicKey)
$sharedSecretBob = [Curve25519]::GetSharedSecret($bob.PrivateKey, $alice.PublicKey)
```
